# Explore OceanVision

Open [the live prototype](https://oceanembed-prototype.vercel.app/). You do not need to install the private model or download ocean datasets.

1. Choose a date within the available archive.
2. Select a depth to inspect its temperature map.
3. Select an ocean point to view the complete temperature profile and 3D water column.
4. Open Validation to inspect benchmark scores and their uncertainty labels.

The first reconstruction for a date can take longer than later requests. The interface reports loading and model availability. Archive reconstruction does not imply a forecast for dates beyond the available data.

For a guided presentation, [watch the pitch](https://youtu.be/BSgT3coOmeM).
